# Bingo Ninja de Suma y Resta · 6° Básico

Juego de bingo para la clase de matemática: sumas y restas con números naturales, decimales y fracciones.

- **Bombo animado**: se saca una bolita con un símbolo ninja y aparece una misión: una operación fácil o un problema tipo "Juanito tenía…". Los niños lo resuelven y buscan el resultado en su cartón.
- **45 cartones de 3×3** en PDF (`Cartones_Bingo_SumaResta.pdf`), 8 por hoja carta (6 hojas, con una hoja en blanco entre cada una), en blanco y negro. Columnas: naturales · decimales · fracciones.
- **Revisar cartón**: se toca el número del cartón y dice si tiene línea o bingo.
- **Solucionario** con el desarrollo de cada problema.
- Funciona en TV, pantalla táctil, PC, tablet y teléfono.

Abrir `index.html` en el navegador (no necesita instalar nada).
